Installing on Android? Choose the APK.

If prompted, allow your browser or file manager to install the app. Install the latest APK over your current version. Do not uninstall first. Back up your library before updating; backups do not include audio files.

Back up your library before updating.

Use Settings → Backup & restore → Back up. The backup contains library data, not audio files. Install updates over the existing app to keep its data.

Optional encrypted sync shares history, favorites, positions and bookmarks. Audio files and folder permissions stay on each device. Update all paired devices for large-library sync.

What’s new

Release notes

  • Sync and backup now preserve both editions when two copies of a book cannot be safely matched. Each keeps its bookmarks and listening position, while other books continue to sync.
  • If another device syncs during an interrupted upload, pending changes can now go through. A device with a complete library copy can also repair an incomplete copy on the server.
  • Long, unfinished books resume in the saved chapter more reliably. Leaving a book page also cancels playback that was still preparing to start.
  • More online books offer playable samples. On affected catalogues, chapters now appear even when their duration is unknown.
  • At large text sizes, book details, toolbar subtitles and mini-player controls stay readable. Long titles in search results can now wrap to a second line.
More release details

Behavior changes

  • Downloading a different edition with the same title now creates a separate folder, protecting the first download.
  • When restoring a backup, **Merge** keeps entries you added to your ignore list. **Replace** uses the list from the backup, even when it is empty.
  • Settings now shows your sync code and pairing status without a duplicate pop-up. Incomplete syncs still show an alert. Before you delete the shared server copy, a warning explains that each device keeps its local library, but other devices may lose the option to restore from the server.

BREAKING CHANGES

  • Backups that contain conflicting copies of a book require STPlayer 0.1.101 or later to restore.

Risks / What to test

  • [ ] Interrupt a sync, make a change on the other device, then sync again. Check that bookmarks and favorites from both devices are present.
  • [ ] Download two editions with the same title. Play each offline, then back up and restore the library. Check each edition’s bookmarks and listening position.
  • [ ] Play an online sample, then resume a long book from History. Check that the right chapter plays.
  • [ ] At 200% system font size, check book details, toolbar subtitles and mini-player controls on a narrow screen.
