Installing on Android? Choose the APK.

If prompted, allow your browser or file manager to install the app. Install the latest APK over your current version. Do not uninstall first. Back up your library before updating; backups do not include audio files.

Back up your library before updating.

Use Settings → Backup & restore → Back up. The backup contains library data, not audio files. Install updates over the existing app to keep its data.

Optional encrypted sync shares history, favorites, positions and bookmarks. Audio files and folder permissions stay on each device. Update all paired devices for large-library sync.

What’s new

Release notes

  • Fixed catalogue loading problems.
  • Improved navigation with a TV remote.
  • Restored missing book covers and kept loaded thumbnails visible while browsing.
  • Fixed incorrect book details and missing cover art when resuming playback or using connected playback controls.
  • Improved recovery when access to a library folder is lost.
  • Preserved local settings changes when a failed sync is rolled back.
More release details

Behavior changes

  • The last selected book is now remembered across app restarts for connected playback controls.

BREAKING CHANGES

None

Risks / What to test

  • Check catalogue loading and TV remote navigation.
  • Restart the app, resume playback, and verify the selected book and cover in connected playback controls.
  • Check covers while scrolling and reopening books.
  • Restore folder access and confirm downloaded books remain playable.
  • Confirm local settings changes survive a failed sync.

These checks were not run for these notes; device behaviour remains unverified.
